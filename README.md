# StudyPilot AI

StudyPilot AI is an adaptive learning and career preparation platform.

## Current Architecture

- React frontend
- Node.js + Express backend
- Microservices architecture
- PostgreSQL
- Redis
- Qdrant
- RAG
- LLM integration
- Docker
- GitHub Actions CI/CD
